Objectives

Project Objectives

  • Stop proxy attendance: ensure a student can only be marked present from their own registered device, during the live class.
  • Authenticate users: let only verified students, faculty and administrators log in, each with access limited to their role.
  • Protect record integrity: make every attendance record tamper-evident so that any change is detected and located.
  • Provide verifiable reports: produce signed session reports that anyone can check without access to the server or database.
  • Save class time: replace roll call with a scan that takes a few seconds, and automate reports and defaulter lists.
  • Demonstrate the security: test every mechanism with live attacks and document the remaining limitations.
