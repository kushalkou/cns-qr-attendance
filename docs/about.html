About the Project

The project applies course concepts (message authentication, key derivation, digital signatures, hash functions, password hashing and transport security) to a problem every student knows: proxy attendance. The goal was a system simple enough to explain in a few minutes, but built and tested like a real security product, including a threat model and a live attack demonstration.
